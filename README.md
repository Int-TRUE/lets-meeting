# 로봇집사 / ROBOT BUTLER

Topic부터 회의 요약까지 함께하는 회의 공간. 승인된 로봇집사 v1.0 디자인을 기준으로 공통 UI와 홈 화면을 구현합니다.

## 실행

Node.js 22.14 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소로 접속하세요. 이 앱은 **디자인 미리보기**입니다. 화면 상단에 예시 데이터임을 표시하며, 실계정 로그인·예약·알림 전송·파일 다운로드는 연결하지 않습니다. 예시 시각은 2026-10-20 13:30 (Asia/Seoul)으로 고정되어 있습니다.

하단의 **미리보기 상태**를 펼쳐 정상, 회의만 없는 상태, 전체 빈 상태, 로딩, 오류, 권한 없음, 세션 만료를 확인할 수 있습니다. 예시 사용자도 변경할 수 있습니다. 이 도구는 실제 권한을 변경하지 않습니다.

## 구현 범위

- 02 홈: 임박한 회의, 시간순 오늘 일정, 작성 권한이 있는 요약 수, 나의 Topic.
- 03 검색: Topic/회의 구분, 검색어 강조, 필터, 검색 후 상세 이동·뒤로가기 복원, 키보드 포커스.
- 04 빈 홈: 회의 없음과 참여 Topic 없음을 구분.
- 공통: 앱 프레임, 버튼, 필드, 카드, 배지, 참석자, 모달, 단계 표시, 로딩·빈 상태·오류.
- 링크 확인용: Topic 목록·Topic/회의 읽기 전용 미리보기, 필수 알림 잠금 표시. 이 페이지들은 전체 상세 화면 구현 완료를 뜻하지 않습니다.

Topic 생성, 회의실 연동, 인증, 실제 데이터 저장은 다음 범위입니다. 관리 기능이나 가짜 미읽음 수는 노출하지 않습니다.

## 구조와 기준

React + TypeScript + Vite, React Router, 일반 CSS를 사용합니다. 화면 → 데이터 저장소 인터페이스 → 조회·권한 규칙으로 분리하고, 외부 연동이 확정되면 미리보기 어댑터를 교체합니다. 현재의 클라이언트 필터는 실제 보안 경계가 아닙니다.

## 검증

```sh
npm run tokens:check
npm run build
npm test
npm run test:e2e
```

브라우저 검증은 로컬 Chrome을 사용합니다. CI에서는 Playwright Chromium을 설치하여 실행합니다. 1440×900, 1024×768, 390×844를 검사하며 결과 캡처는 `test-results/`에 생성됩니다. `PLAYWRIGHT_CHANNEL=chromium`으로 로컬에서도 Playwright Chromium을 선택할 수 있습니다.

`npm run tokens`로 디자인 JSON에서 CSS 색상·그림자·글꼴 토큰을 재생성합니다. 작업은 `task/*` 브랜치에서 진행하고 `master` 대상 PR로 검토합니다.
