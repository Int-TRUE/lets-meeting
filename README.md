# 로봇집사 / ROBOT BUTLER

Topic부터 회의 요약까지 함께하는 회의 공간. 승인된 v1.0 디자인을 바탕으로 Topic → 회의 생성·예약 → 자료·요약 → 알림·운영 화면을 연결한 **개발용 미리보기**입니다.

## 실행

Node.js 22.14 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

표시되는 로컬 주소로 접속하세요. 예시 시각은 **2026-10-20 13:30 (Asia/Seoul)**입니다. 이 미리보기는 실제 회사 계정·원텔 예약·Mattermost에 연결하지 않습니다.

## 사용할 수 있는 흐름

1. **Topic**: 전체/관리 중/참여 중 필터, 주제 생성, 관리자 선택, Owner 정보·관리자 추가, 역할별 회의 히스토리.
2. **회의 생성·예시 예약**: 기본 정보 → 장소·시간 → 참가자·자료의 정확히 3단계. 명동·분당의 예시 회의실, 30분 슬롯, 저장 직전 충돌 재검사, 중복 제출 방지, 초안 복원, 수정·취소.
3. **자료·요약**: 직접 등록한 파일의 저장·교체·다운로드, 생성자의 요약 임시 저장, 확인 후 명시적 완료. 미리보기 파일 편집은 미완료 회의의 생성자로 한정합니다.
4. **알림·운영**: 개인 선택 알림·리마인드 저장, 필수 생성·변경·취소 알림 잠금, 운영 전용 이벤트 이력·필터·상세, 예시 회의실 목록·관리 화면.

홈·검색도 같은 SQLite DB에서 생성·수정한 데이터에 맞춰 갱신합니다. 첫 실행 시 `data/robot-butler.sqlite`에 사용자 15명·Topic 6개·회의 15개·회의실 5개와 더미 PDF를 넣습니다. 이후 재시작해도 수정 내용은 보존됩니다. 탭의 예시 사용자와 작성 중인 초안만 sessionStorage를 사용합니다. 서로 다른 브라우저에서도 같은 DB와 첨부 파일을 읽습니다. [DB 구성과 사례](docs/DATABASE.md)를 참고하세요.

하단 **미리보기 상태**에서 화면 예외와 예시 사용자를 선택할 수 있습니다. 기본은 `나(데모)`입니다. 전산기기교체에서 최승호는 Owner, 김주형·이승엽은 Master, 박나형·나는 Attendee입니다. 기존 브라우저의 선택은 유지됩니다. 회의에 초대하면 Topic Attendee가 되며, 운영 관리자라는 이유로 회의 본문을 열람할 수는 없습니다.

## 실제 연동과 미정 정책

이 구현의 저장·권한·예약 경합 검사는 로컬 미리보기 어댑터 범위입니다. **생산 환경의 인증·권한을 제공하는 서버가 아닙니다.** 실제 서비스에는 서버 세션, 직원 API, 예약 트랜잭션, 파일 접근 통제, Mattermost 전송기를 연결해야 합니다. 이벤트 이력은 `미전송 · 미연결`로 기록하며 가짜 발송 성공을 표시하지 않습니다.

Owner 위임·영구 삭제, 기존 관리자 제거, 완료 회의 재개·완료 후 요약 수정, 파일 삭제, 외부 회의실 변경과 재전송은 정책 확정 전 활성화하지 않습니다. 서비스 내 알림함은 보조 제안이므로 이번 범위에 추가하지 않습니다. 원본 보드의 회의실 사진·길찾기를 실제 안내로 쓰지 않습니다.

로컬에서는 `npm run dev`의 SQLite API를 사용하고, [Vercel 배포](https://robot-butler.vercel.app/)에서는 Node Function과 Neon PostgreSQL을 사용합니다. 같은 사례 데이터로 시작하며 로컬·배포·Preview 브랜치 데이터는 별도로 보존합니다. `vite preview`에는 서버 API가 없습니다. 기존 IndexedDB 어댑터는 `VITE_DATA_MODE=fixture`인 격리 테스트에서만 사용하며, 실제 앱의 DB 장애를 숨기는 대체 저장소로 사용하지 않습니다.

## 검증

```sh
npm run check
```

토큰 일치·코드 형식·타입·빌드·도메인/저장소 테스트·브라우저 흐름을 검사합니다. 로컬 Chrome을 사용하고 CI는 Playwright Chromium을 설치합니다. `PLAYWRIGHT_CHANNEL=chromium`으로 로컬 Playwright Chromium을 선택할 수 있습니다. 1440×900, 1024×768, 390×844 캡처는 `test-results/`에 생성됩니다.

`npm run tokens`로 디자인 JSON에서 공통 CSS 토큰을 재생성합니다.
