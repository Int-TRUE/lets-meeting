## 0.2 — Topic부터 운영 화면까지 (2026-10-20)

브랜치 `task/robot-butler-workflows`. 기존 홈 브랜치의 검증본을 기반으로 후속 기능을 순서대로 확장했다. 아래 기록은 **로컬 미리보기 기능**에 관한 것이며 회사 서비스의 실제 연동 완료를 의미하지 않는다.

저장은 IndexedDB 트랜잭션으로 처리한다. 생성 요청은 사용자별 키로 중복 제거하고, 예약 충돌·권한·동시 변경을 저장 계층에서도 확인한다. 파일은 Blob으로 보존하고 다운로드 요청에서 현재 권한을 다시 확인한다. 생산 빌드의 미리보기 쓰기는 기본 차단한다. 실제 인증된 서버의 보안 검증을 대체하지 않는다.

로컬 검증: 빌드·토큰·형식·공백 검사 통과, 도메인/저장소 테스트 **16개**, 브라우저 검사 **51개** 통과. 1440×900·1024×768·390×844에서 생성→자료→수정→취소, 새로고침, 요약 임시 저장→완료, 개인 설정, 관리자 접근을 검증했다. 관리자 모바일 필터와 표는 캡처 확인 후 별도 시나리오 3개로 재검증했다. 기존 원격 검사에서 발견한 검색 모달 Tab 준비 시점 문제는 layout effect와 준비 상태 확인으로 수정했다. 원격 CI의 최종 결과는 PR 검사에서 확인한다.

## 시안 대비 차이와 남은 범위

비교 기준은 `01-brand-and-entry.png` 및 홈 정보 구조 참고 보드다. 카드·문구·카운트는 실제 텍스트와 공통 컴포넌트로 구현했으며 예시 값은 하나의 데이터에서 계산한다.

- 원본 보드의 서비스 내 알림함·가짜 미읽음 수를 제외했다(D14). 벨은 알림 설정으로 연결한다.
- Topic 멤버 수의 공개 범위가 미정이므로 인원수를 임의 표시하지 않는다(D15). 역할과 접근 가능한 회의 수만 표시한다.
- 개별 투명 로고·캐릭터 파일이 없어 최신 승인 보드의 캐릭터 부분만 CSS로 잘라 쓴다(D18). 홈 안내에는 승인된 집사 의상 포즈, 빈 홈에는 태블릿 포즈를 사용한다. 개별 자산 제공 후 교체한다.
- 모바일에서는 안내 캐릭터를 생략하고 메뉴·브랜드·본문 공간을 확보한다. 카드 한 열과 메뉴 서랍은 명세의 반응형 기본안이다(D17).
- 상단 예시 데이터 안내와 하단 미리보기 상태 도구는 개발용이며 출시 전 실제 데이터 어댑터와 함께 정리한다. 예시 시각은 Asia/Seoul 2026-10-20 13:30이다.
- 01 로그인, 05–20 전체 화면, Topic 생성·수정·삭제, 예약·알림·자료·요약 저장은 이번 구현 완료 범위가 아니다. 링크 연결용 읽기 화면을 해당 기능 전체 완료로 간주하지 않는다.
- 실제 서비스 전환에는 서버 권한 검증, SSO, 원텔 예약, Mattermost, 파일 접근 통제와 미정 정책 확정이 필요하다. 가용 슬롯이나 실제 전송 성공을 모의로 표시하지 않는다.
