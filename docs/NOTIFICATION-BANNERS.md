# 로봇집사 알림 배너

내장 imagegen 도구로 제작했으며 원본 참조는 `src/assets/mascot-tablet-hq.png`다. 생성 후 JPEG로 크기·용량만 최적화했다. 결과는 `public/notification-banners/created.jpg`, `changed.jpg`, `cancelled.jpg`, `late.jpg`이며 900×300이다.

공통 프롬프트: 승인 마스코트의 흰 둥근 얼굴·파란 귀 장식·파란 코·검은 눈·분홍 볼·네이비 집사 재킷·파란 나비넥타이와 부드러운 3D 스타일을 유지한다. 흰색·연한 블루·민트의 3:1 가로 배너, 작은 화면에서도 읽히는 네이비 한글, 단순한 배경.

- 생성: 오른쪽 집사가 태블릿으로 일정을 확인하며 왼쪽 문구는 정확히 “회의가 생성되었어요”.
- 변경: 생성 배너에서 다른 요소는 유지하고 문구만 “회의가 변경되었어요”로 교체.
- 취소: 생성 배너에서 다른 요소는 유지하고 문구만 “회의가 취소되었어요”로 교체.
- 지각: 집사가 열린 회의실 문에서 안으로 안내하고 회의 테이블의 동료들이 도착한 사람을 바라본다. 밝고 환영하는 분위기. 문구는 “모두가 기다리고 있어요!”.
