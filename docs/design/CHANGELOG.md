# 변경 이력

## 개발 0.1 — 2026-10-20

- 사용자 요청에 따라 공통 UI와 02 홈·03 검색·04 빈 홈 구현을 시작.
- D19 일부 결정: 사용자에게 위임받은 아키텍처 판단으로 React·TypeScript·Vite, 화면/컴포넌트/도메인/저장소 경계 채택. 상세 근거는 [아키텍처](../ARCHITECTURE.md)에 기록.
- 서버 인증·예약·알림·내부망과 기타 미정 업무 정책은 확정하지 않음.
- 최신 원격 초기 커밋을 기준으로 task 브랜치에서 구현. 원본 보드는 보존하고, 개별 캐릭터 자산 제공 전 승인 보드의 캐릭터 부분만 장식으로 사용.
- 구현·검증 범위와 캡처는 [구현 기록](../IMPLEMENTATION.md)에 별도 기록.

## v1.0 — 2026-10-20

- 사용자 승인: 전체 스타일은 미팅집사 1안, 홈 구성은 모여 2안.
- 사용자 승인: 첨부 캐릭터에 집사 의상을 적용, 서비스명 로봇집사 확정.
- 20개 화면의 시안과 최종 브랜드 보드를 인계 기준으로 정리.
- 개발용 색상·간격·글꼴·컴포넌트·반응형 기본값 정의. 이미지에서 측정한 절대값이 아님을 명시.
- 3단계 회의 생성, 명시적 완료, 필수 알림 잠금, 역할 구분, 옛 브랜드 교체 등 이미지 교정 기준 작성.
- 미정 연동·운영 정책과 보조 제안을 별도 목록화.
- AGENTS.md 및 프로젝트 지침 추가용 문구 준비. 프로젝트 설정을 직접 변경한 것은 아님.
- 애플리케이션 구현·외부 연동·배포 없음.
