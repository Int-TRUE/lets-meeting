- 사용자 허가에 따라 투명 얼굴 로고와 성공 일러스트를 imagegen으로 제작. 알림 SVG와 로그인 배경 장식 제작.

- 검색 메타와 참가자, 히스토리 참가자·요약, 요약 화면 일시·장소·주최자, 취소 확인 항목 추가.

## 2026-10-22 — 기존 3D 마스코트 화질 개선

사용자 지시에 따라 기존 3D 캐릭터 스타일과 포즈를 유지한다. 로그인은 시안 보드의 작은 부분을 확대하던 방식에서 개별 1536×1024 투명 배경 환영 에셋으로 교체한다. 홈과 얼굴 로고는 기존 PNG 원본을 그대로 유지한다. 로그인·홈의 약한 외곽 알파만 표시 단계에서 정리하며 원본 RGB는 변경하지 않는다. 제공된 원본 SVG는 없으며 복원 PNG를 벡터라고 표시하지 않는다. 로그인 개별 복원본은 시안 보드와 미세한 재질·형태 차이가 있을 수 있다.

빈 홈의 태블릿 포즈도 시안 보드 확대 대신 개별 1536×1024 투명 복원본으로 적용했다. 양쪽 구름을 포함한 전체 이미지를 표시하며, 같은 3D 스타일을 유지한다.
