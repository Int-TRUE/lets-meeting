# 변경 이력

## 데스크톱 시안 치수·전체 화면 적용 — 2026-10-20

- 사용자 선택 “홈부터 맞춘 뒤 전체 화면에 적용”에 따라 ZIP 앱 영역을 측정하고 홈 1484×992 기준 프레임을 적용.
- 공통 메뉴 256px·검색 영역 96px, 흰 배경·네이비·파랑, 카드·타이포그래피·여백을 조정. 미리보기 안내는 도구 내부에 유지.
- 로그인과 Topic·예약·생성 결과·요약·알림의 시안 배치를 반영. 회의 수정의 변경 전 안내를 유지.
- 19개 화면을 같은 크기의 원본과 비교하고 실제 PNG·겹쳐 보기 보고서를 보존. [측정/차이 기록](DESKTOP-REFERENCE.md).
- 새 이미지 생성이나 임의 폰트 다운로드 없이 기존 자산 사용. 정확한 이미지·폰트 및 미정 정책 때문에 남은 차이를 화면별로 명시.
- 로컬 단위 16개·브라우저 52개 통과, 데스크톱 전용 캡처 중복 실행 2개 제외.

## 홈 캐릭터 잘림 수정 — 2026-10-20

- 사용자가 지적한 캐릭터 하단 잘림을 수정. 보드 확대·오프셋·clip-path 방식을 제거하고 투명 복원 에셋 전체를 표시.
- 내장 imagegen 편집 도구 사용. 프롬프트 요지: 승인 홈 캐릭터의 정체성·파란 귀·분홍 볼·네이비 재킷을 유지하고, 화면 왼쪽의 흔드는 손과 오른쪽 노란 선을 복원하며 글자·배경을 제거하고 완전한 상반신을 투명 여백 안에 배치.
- 에셋: `src/assets/home-mascot.png`. 원본에서 글자에 가려진 부분은 복원된 부분이며 원본 픽셀과 동일하다는 의미는 아님.
- PC·태블릿·모바일 홈 캡처와 빌드 확인.

## 홈 시안 정합성 보정 — 2026-10-20

- 사용자가 추가 첨부한 홈 이미지를 02 홈의 배치·색상·장식 기준으로 반영. 원본은 `assets/reference-home-user-2026-10-20.png`에 보존.
- 인사말과 임박한 회의를 왼쪽, 오늘 일정을 오른쪽 상단에 배치하고 달력 SVG, 참석자 원형 아이콘, 요약 대기 표시, 낮은 Topic 카드를 복원.
- 홈 전용 색상 토큰으로 선명한 파랑·네이비·옅은 파랑을 반영. 다른 화면의 기존 토큰은 유지.
- 이미지 숫자를 복사하지 않고 저장된 회의·참석자·Topic 수와 현재 날짜를 표시. 미정인 Topic 멤버 수는 추가하지 않음. 작은 화면에서는 겹침 없이 세로 배치.

## 개발 0.2 — 2026-10-20

- 사용자 요청에 따라 Topic → 3단계 회의 생성·예시 예약 → 자료·요약 → 알림·관리자 화면을 순서대로 구현.
- D19: 로컬 미리보기 영속화는 IndexedDB readwrite 트랜잭션, 파일은 Blob, 입력 초안과 예시 사용자 세션은 sessionStorage 사용. 실제 서버·내부망 결정은 보류.
- 생성 중복 제거·예약 최종 충돌 검사·권한·revision 검사·필수 알림 잠금·명시적 완료를 저장 어댑터에서도 적용.
- 모의 성공은 개발 환경으로 제한하고 생산 빌드의 미리보기 쓰기는 기본 차단.
- 실제 SSO/원텔/Mattermost, Owner 위임·삭제·자료 실제 권한·완료 후 수정·외부 회의실 관리 등 기존 미정 사항은 확정하지 않음.
- 사용자 명시 지시에 따라 검증 후 커밋·게시·PR·머지는 추가 확인 없이 진행. 기본 브랜치 직접 푸시 금지는 유지.
