# 디자인 시스템

v1.0 · 아래 값은 승인 시각 방향을 일관된 UI로 재현하기 위한 개발 기본값이다. 스크린샷 픽셀을 그대로 추출한 값이 아니다.

색상만으로 상태를 전달하지 않는다. 모든 상태에는 텍스트와 필요 시 아이콘을 붙인다. 옅은 경계선은 패널 장식용이다. 입력란 경계·포커스·선택 등 식별에 필요한 컨트롤에는 더 진한 토큰을 사용한다. 흰색 글자는 primary, primaryHover 등 충분한 대비가 있는 바탕에만 사용한다.

## 글꼴과 간격

- 기본 글꼴: `Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`, `sans-serif`. 폰트 배포 시 라이선스와 내부망 로딩 방식을 확인한다. 준비 전 시스템 글꼴 사용 가능.
- 본문 16px/1.6, 보조 14px/1.5, 작은 메타 12px/1.5. 중요 정보에 12px 미만 금지.
- 페이지 제목 28px/1.35/700, 홈 인사 32px/1.35/700, 섹션 20px/1.4/600, 카드 제목 18px/1.4/600.
- 간격은 4, 8, 12, 16, 24, 32, 48px 체계. 카드 내부 기본 24px, 카드 간격 24px, 작은 그룹 8–12px.
- 모서리: 입력·버튼 12px, 카드 20px, 큰 패널 24px, 상태 배지 999px.
- 그림자: `0 4px 20px rgba(23,33,61,0.06)`. 다중 강한 그림자·유리 효과·과도한 그라데이션 금지.

## 앱 프레임과 화면 크기

| 구간 | 개발 기본 규칙 |
| --- | --- |
| 데스크톱 ≥1200px | 왼쪽 208px 내비게이션, 본문 패딩 32px, 헤더 최소 72px, 내용 최대 1440px |
| 태블릿 768–1199px | 내비게이션 72px 아이콘 레일 또는 열리는 메뉴, 라벨을 접근성 이름으로 유지, 본문 24px |
| 모바일 <768px | 메뉴 버튼과 서랍, 본문 16px, 카드 한 열, 폼 버튼 세로 배치 가능 |

원 시안은 데스크톱 중심이다. 태블릿·모바일 규칙은 대응을 위한 기본 설계이며 별도 모바일 시안 승인으로 간주하지 않는다. 1440×900, 1024×768, 390×844에서 검증한다. 긴 표는 제목·주요 행동을 유지하면서 내부 스크롤이나 목록 형태로 바꾼다. 페이지 전체 가로 넘침은 금지한다.

홈은 임박한 회의와 오늘 일정을 약 3:2 비율로 두고 Topic을 아래에 둔다. 폭이 부족하면 임박한 회의 → 오늘 일정 → 나의 Topic 순서로 쌓는다. 좌측 메뉴와 하단 독을 중복 제공하지 않는다. 관리자 메뉴는 관리자에게만 추가한다.

## 캐릭터와 브랜드

- 사용자 제공 캐릭터의 얼굴·파란 귀 장식·하얀 몸·볼터치를 보존한다. 옷은 네이비 집사 재킷, 흰 셔츠 앞판, 나비넥타이다.
- 로그인은 큰 환영 포즈, 빈 상태는 태블릿 포즈, 홈은 작은 안내 포즈. 관리 표나 폼마다 반복 장식하지 않는다.
- 작은 로고는 동일 캐릭터 얼굴을 단순화한다. “로봇집사” 표기를 우선하고 보조 영문은 ROBOT BUTLER로 통일한다.
- 캐릭터는 제목·버튼을 가리지 않고 일반 정보와 구분된 영역을 차지한다. 장식 이미지는 빈 alt, 의미 있는 안내 이미지는 간결한 alt를 사용한다.
- 현재 보드는 참고 이미지다. 투명 배경 캐릭터, 벡터 로고, 포즈별 자산은 아직 납품되지 않았다. 별도 제작 전 기존 다른 캐릭터를 임시 출시하지 않는다.

## 상호작용과 접근성

- 모든 행동에 키보드 접근, 선명한 포커스, 읽을 수 있는 상태/오류 문구를 제공한다.
- 일반 텍스트 대비 목표 4.5:1, 큰 텍스트·필수 UI 표시 3:1. 색상 이름만으로 적합성을 가정하지 말고 실제 조합을 검사한다.
- 포커스 링은 primary 2px + 2px offset. 선택 상태는 경계·체크·라벨을 함께 쓴다.
- 이동은 실제 링크, 변경은 버튼, 필드에는 label. 모달은 이름과 설명, 포커스 복귀 제공.
- 동작 전환 120–200ms, 사용자의 reduced-motion을 존중한다. 회의실 길찾기 애니메이션에는 정적 경로 대체를 제공한다.
- 저장 중 중복 제출 방지. 결과 성공/실패를 알리며 실패 시 입력을 보존한다.
