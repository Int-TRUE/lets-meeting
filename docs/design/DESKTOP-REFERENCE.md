# 데스크톱 시안 재현 기준과 차이 기록

2026-10-20 사용자 요청: 새 디자인 제안 없이 ZIP 시안을 기준으로 홈부터 전체 화면에 적용. 주 사용 환경은 컴퓨터 브라우저.

## 측정 기준

패키지에는 1536×1024 PNG 합성 보드 5장과 홈 참고 보드가 있다. Figma, 개별 화면의 원래 viewport, CSS 수치, 폰트·아이콘 원본은 없다. 따라서 아래 값은 **합성 보드의 앱 사각형을 측정한 값과 그 2배 표시 기준**이며 원본 디자인 도구의 확정 수치가 아니다. 보드 밖 번호·설명·여백은 앱에 포함하지 않는다.

홈 앱 영역은 보드 01의 `(776, 34, 742, 496)`이다. 이를 2배로 표시한 1484×992를 주 비교 크기로 사용한다. 나머지 화면은 `tests/design-reference.spec.ts`에 기록한 앱 영역의 폭·높이 각각 2배로 캡처한다. 같은 화면의 원본과 결과는 항상 같은 크기다. 일반 PC 1440×900과 태블릿·모바일의 넘침 검사는 별도로 유지한다.

글꼴은 패키지가 Pretendard 우선의 fallback 목록만 지정한다. 실제 폰트 파일과 원본 보드의 정확한 폰트 이름은 제공되지 않았다. 현재 설치된 시스템 한글 글꼴로 표시되므로 글자 폭·획·줄바꿈 차이가 남는다. 임의 폰트 다운로드나 새 아이콘/캐릭터 생성은 이번 작업에서 하지 않는다.

## 기존 스타일 충돌과 수정

- `styles.css`: 208px 메뉴, 회색 전체 배경, 20px 카드, 큰 그림자, 작은 workflow 글자.
- `home.css`: 홈에만 파란색 적용. 상속된 제목 색은 공통 body의 이전 색을 쓰는 부분이 있었다.
- 시안에 없는 위쪽 36px 미리보기 배너와 사이드바 하단 홍보 문구가 콘텐츠 좌표를 바꿨다.
- `desktop-reference.css`를 마지막에 적용해 프레임·표면·PC 치수를 통일했다. 미리보기 안내는 하단 도구를 펼쳤을 때 확인하도록 옮겼으며 저장 결과의 미연동 안내는 유지했다.
- Topic 목록은 원본의 2열, 알림 설정은 원본의 이벤트/리마인드/방해금지 3열로 보정했다.
- 예약 2단계는 별도 오른쪽 요약 때문에 선택 영역이 지나치게 좁아졌으므로 선택 화면을 전체 폭으로 표시한다. 예약 요약은 선택 영역 안에서 유지한다.
- 검색 모달의 중복 제목은 접근성 이름으로 남기고 시각적으로 숨겨 검색 입력을 위로 옮겼다.

## 정확한 재현에 필요한 추가 자료

1. Figma 원본 또는 각 화면의 단독 이미지와 원래 데스크톱 viewport·배율.
2. 홈/로그인/빈 상태의 투명 캐릭터, 작은 로고 벡터. 현재 홈 복원본은 원본과 동일하지 않다.
3. 정확한 글꼴 이름, 굵기별 WOFF2와 사용 권한.
4. 메뉴·Topic·달력·알림 배너의 SVG 또는 원본 PNG.
5. 회의실 사진과 실제 길찾기 이미지. 실제 안내로 쓸 수 있는 자료가 없다.
6. 프로필 사진을 사용할 경우 허용된 예시 이미지. 현재는 이름 이니셜을 표시한다.

## 정책 때문에 유지되는 차이

시각 보드의 예시 숫자·권한·4단계 표시·무조건 성공을 그대로 복사하지 않는다. 패키지가 명시적으로 교정한 규칙을 유지한다.

- 3개 입력 단계와 생성 결과. 시안의 4단계 번호는 복제하지 않는다.
- Topic/회의/참가자 수는 접근 가능한 실제 미리보기 데이터와 일치한다.
- Topic 멤버 노출, Owner 위임·삭제, 자료 정책, 완료 후 수정은 미정 범위를 확정하지 않는다.
- 18 서비스 알림함은 선택 제안이므로 신규 구현하지 않는다.
- 실제 인증·예약·알림이 미연결인 상태는 성공으로 꾸미지 않는다. 로그인 화면의 회사 로그인은 비활성이고 미리보기 링크를 제공한다.
- 회의실 사진·지도·프로필 원본이 없는 부분은 현재 텍스트/이니셜 안내를 유지하고 시안과 다른 것으로 기록한다.
- 원본에서 겹친 홈 캐릭터·제목은 문서 규칙에 따라 겹치지 않게 표시한다.

## 캡처 검증

`tests/design-reference.spec.ts`는 화면 01–17, 19–20의 실제 경로/상태를 열고, 해당 보드 앱 영역과 같은 크기의 캡처를 만든다. 16은 명세상 별도 예정 회의 취소 확인 상태다. 원본 16의 완료 화면 위 취소창 혼합은 재현하지 않는다.

2026-10-20 최종 로컬 검증: 토큰·형식·빌드, 단위 테스트 16개, 브라우저 테스트 52개 통과. 데스크톱 전용 비교 시나리오의 태블릿·모바일 실행 2개만 의도적으로 제외했다. 기존 기능 검사는 세 화면 크기 모두 통과했다.

[19개 화면 비교 보고서](../qa/desktop-reference/index.html)에서 나란히 보기와 반투명 겹쳐 보기를 제공한다. `node scripts/build-design-review.mjs`로 최종 브라우저 결과를 보존했다. 자동 테스트는 화면 접근·기능·가로 넘침을 검증하며 픽셀 일치를 판정하지 않는다. 캡처를 직접 확인해 빈 홈 중앙 정렬, Topic 생성창 버튼 잘림, 예약 화면 높이, 요약 입력과 버튼 위치를 수정했다. 회의 수정의 변경 전 장소·시간 안내가 숨겨지는 회귀도 수정하고 재검증했다.

홈 1484×992에서 회의 카드 실제 `(288,304,602,338)`는 원본 추정 `(292,298,604,340)`에 가깝게 맞췄다. 오늘 일정 실제 `(914,120,538,522)`와 원본 추정 `(920,120,540,530)`, Topic 카드 시작 y750과 원본 약 y744를 비교했다. 글꼴·이미지·일정 세부 글자 크기에는 차이가 남는다.

전체 화면에 공통 프레임·색상·타이포그래피를 적용했지만 모든 화면의 구조까지 동일해진 것은 아니다. 특히 08 Topic 설정은 멤버 표 대신 기존 정보 수정 폼, 14 회의 수정은 옆 패널 대신 기존 3단계 화면, 20 회의실 관리는 수정 폼 대신 조회 화면이다. 09 안건과 15 후속 할 일도 개별 목록 대신 텍스트 입력이다. 각 화면의 남은 차이는 비교 보고서에 명시했으며, 이 작업을 픽셀 단위 재현 완료로 간주하지 않는다.
