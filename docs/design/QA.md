# 수용 기준과 검증

이 목록은 향후 구현의 검사 기준이다. 이번 문서 패키지가 애플리케이션 테스트를 통과했다는 뜻은 아니다.

## 공통 시각 기준

- [ ] 모든 사용자 화면에 로봇집사/ROBOT BUTLER. 미팅집사·모여 옛 이름 없음
- [ ] 승인 캐릭터 얼굴·귀 장식·의상 유지. 텍스트·행동 가리지 않음
- [ ] 토큰·공통 컴포넌트 일관성, 밝은 화이트·블루·민트 스타일
- [ ] 홈은 임박한 회의/오늘 일정/Topic 배치. 중복 하단 독 없음
- [ ] 카드·입력·버튼 간격과 제목 위계 일관성
- [ ] 예시 개수와 실제 데이터 개수 일치, 임의 인원·파일 제한 없음
- [ ] 개발용 검토 주석을 일반 사용자 문구로 그대로 복사하지 않음
- [ ] 1440×900 / 1024×768 / 390×844에서 겹침·페이지 가로 넘침 없음

## 핵심 기능·권한 시나리오

| 시나리오 | 기대 결과 |
| --- | --- |
| Owner/Master/Attendee로 같은 Topic 접근 | Owner·Master 전체 조회, Attendee 초대된 회의만 조회 |
| Attendee가 숨겨진 회의 URL/API/자료 링크 접근 | 내용과 불필요한 존재 정보 노출 없이 거부 |
| Master가 타인이 생성한 회의 수정 | UI와 서버에서 거부 |
| 회의 생성 1→2→3→4→이전→다음 | 입력 보존, 정확히 4단계 |
| 동일 시간에 다른 사용자가 예약 | 최종 서버 검사에서 충돌 처리, 중복 예약 없음 |
| 생성 버튼 연속 클릭/네트워크 재시도 | 중복 회의·예약·초대 방지 |
| 예약 성공, 알림 실패 | 예약 성공과 알림 실패를 분리 표시·기록 |
| 자료 없음 상태로 D-1 도달 | 자료 미등록 리마인드 제외 |
| 종료 시각 경과, 요약 미완료 | 완료가 아니라 요약 작성 필요 |
| 요약 임시 저장 | 완료 처리·완료 알림 발생하지 않음 |
| 생성자가 요약 저장 및 완료 | 완료 배지와 요약 표시, 길찾기 제외 |
| 예정 회의 취소 | 확인 후 취소·예약 해제·참가자 통지 결과 처리 |
| 필수 알림 해제 시도 | 설정 UI·서버 모두 해제 불가 |
| 검색→상세→뒤로가기 | 검색어·필터·결과 위치 유지 |
| 운영 관리자 메뉴 일반 사용자 접근 | 화면·서버 접근 거부 |

## 접근성·예외

- 히스토리 가로 카드·화살표·낮은 카드 높이와 공통 하단 패널을 확인한다. 카드 선택 전환·키보드 조작·상세 링크, 체크 상태 저장/새로고침 유지와 빈 요약을 확인한다.
- 알림 현황 로딩/결과/빈 상태/오류와 새로고침, 모바일 가로 넘침을 확인한다.

- [ ] 키보드로 메뉴·검색·예약 슬롯·폼·모달 사용 가능
- [ ] 모달 focus trap/Escape/호출 지점 복귀, 필드 label과 오류 연결
- [ ] 실제 글자·컨트롤 대비 검사, 색상 외 상태 표시
- [ ] 긴 한글 제목·파일명·참가자명, 0개/1개/다수 결과 확인
- [ ] loading/empty/error/권한 없음/세션 만료 구분
- [ ] 저장 실패 시 입력 보존, 업로드 실패 개별 처리
- [ ] reduced-motion·정적 길찾기 대체 지원

## PR 및 작업 완료 보고

변경 화면 ID, 비교한 시안 파일, 수행한 테스트, 화면 캡처 또는 검토 결과, 의도적인 차이, 남은 미정 항목, 브랜치·커밋·PR 링크를 기록한다. 실제 실행하지 않은 테스트와 연동을 완료라고 보고하지 않는다.

## 이번 문서 인계의 검증 범위

Markdown 내부 링크, 필수 20개 화면 ID, 토큰 JSON, 이미지 존재·형식·해시, 압축파일 무결성을 검사한다. 애플리케이션·인증·예약·알림 기능 테스트는 구현이 없으므로 대상이 아니다.


## 2026-10-25 회의 생성·자료·회의실 정보 보완

- 사용자 표기는 Topic 대신 **토픽**으로 통일한다. 내부 API·경로명은 유지한다.
- 참가자·관리자 선택은 검색 전 목록을 표시하지 않는다. 시작 시 로그인용 테스트 계정만 조회하고, 직원 검색 API는 이름·팀·직책으로 최대 20명과 추가 결과 여부를 반환한다. 회의 참가자는 해당 토픽 구성원으로 제한한다. 선택한 사람은 칩으로 유지한다.
- 자동 리마인드는 스위치와 선택 카드 UI를 사용한다. 하루 전(24시간)·1시간·30분·10분·5분·3분 전을 복수 선택하며 마지막 선택 해제 시 꺼진다. 서버 검증과 기존 발송·중복 방지 정책에 동일 적용한다.
- 시간 선택 숫자는 20px, 상태는 14px로 표시한다.
- 자료 목록은 교체 대신 삭제를 제공한다. 생성자 권한과 revision을 검사하고 확인 후 삭제한다. 마지막 파일 삭제 시 자료 상태는 등록 예정이며 자동으로 자료 없음으로 바꾸지 않는다.
- 회의실 정보는 대표사진과 가는 법 두 영역으로 나눈다. 등록된 사진·안내도는 모달로 확대하며 Escape·닫기·포커스 복귀를 지원한다. 실제 사진 미제공에 따라 대표사진은 미등록 안내를 사용한다. 사진 URL 연결 후 동일 영역에서 표시한다.
- 검증: 검색 전 빈 상태·250명 검색 결과 제한·토픽 범위, 자료 삭제 권한·충돌·다운로드 차단, 24시간/1시간 알림 발송 시점·중복 방지, 반응형 선택 UI와 확대 모달을 확인한다.
