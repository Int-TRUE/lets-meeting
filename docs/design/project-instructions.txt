[로봇집사 디자인 공통 규칙 — 기존 프로젝트 Git 규칙 아래에 추가]

서비스 이름은 ‘로봇집사 / ROBOT BUTLER’다.
모든 개발 작업의 기본 저장소는 https://github.com/Int-TRUE/lets-meeting.git 이다.
UI 작업 전 저장소의 AGENTS.md와 docs/design/README.md를 읽고, DESIGN-SYSTEM.md, SCREENS.md, BEHAVIOR.md, OPEN-DECISIONS.md, QA.md를 따른다.

디자인은 2026-10-20 승인된 로봇집사 시안을 기준으로 한다.
- 전체 화면: 1안 미팅집사의 밝은 화이트·블루·민트, 둥근 카드와 부드러운 그림자.
- 홈 화면: 2안 모여의 정보 구성(임박한 회의 왼쪽, 오늘 일정 오른쪽, Topic 목록 아래).
- 이름·마스코트: 최신 로봇집사 시안. 하얀 캐릭터의 파란 귀 장식·볼터치를 유지하고 네이비 집사 재킷과 나비넥타이를 사용한다.
- 예전 보드의 ‘미팅집사’·‘모여’ 이름과 옛 마스코트는 제품에 사용하지 않는다.

최신 사용자 결정 → 저장소의 명시적 디자인·동작 명세 → 최신 브랜드 보드와 화면별 시안 순으로 적용한다. 노션 요구사항의 이후 변경과 충돌하면 먼저 확인한다.
시안 이미지의 오타·단계 번호·임의 제한값·예시 데이터는 그대로 구현하지 않고 문서의 교정 기준을 따른다.
공통 토큰과 컴포넌트를 재사용하고, 화면 구조·색상·캐릭터·기능 범위를 임의로 바꾸지 않는다. 큰 변경은 이유와 대안을 제안하고 합의 후 반영한다.
회의는 시간이 지났다고 자동 완료하지 않는다. 생성자가 요약 저장 및 완료를 해야 완료된다. 필수 회의 알림은 해제할 수 없다. 권한은 UI와 서버 모두 검증한다.
SSO, 직원 API, 원텔 예약, 카카오톡, 방해금지, 미정 정책은 실제 동작으로 가정하지 않는다. 모의 데이터는 개발용임을 구분한다.
각 화면의 정상·빈 상태·로딩·오류·권한 상태와 반응형·키보드 사용을 검증한다. 완료 보고에 구현한 화면 ID, 시안 대비 차이, 검사 결과를 포함한다.

디자인 파일이 저장소에 없거나 접근할 수 없으면 임의로 재설계하지 말고 승인 패키지를 확인한다. 첨부한 robot-butler-design-v1.0.zip은 저장소 반영 전에도 동일 기준으로 사용할 수 있다.
